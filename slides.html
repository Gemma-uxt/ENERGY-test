IT 비전공자의 바이브코딩 사례

생성형 AI와의 대화(Vibe Coding)만으로 구축한 사례로서, 기존 전문인력의 영역이었던 데이터 수집·화면제작을 현업부서에서 직접 구축·수정·운영  →  현업 아이디어의 즉시 시스템화 및 확장 가능
구축방법 : AI와 대화로 프로그램 작성·구축 (바이브코딩)
필요한 정보와 화면 형태를 대화로 전달
→ 정보수집·자동실행·웹 구현 프로그래밍을 AI가 수행
오류 발생 시 화면을 캡처하여 전달
→ AI가 원인 분석 후 수정방법 제안 (코딩 수정, 파일교체 등)
구동결과 확인·검증 후 추가사항 요청
→ AI가 구현방안 제공
작동원리 : 작성한 프로그램을 클라우드 서비스에서 실행
코딩된 절차에 따라 이행 (출처지정, 수집주기, 정리·분석, 게시 레이아웃 등)
